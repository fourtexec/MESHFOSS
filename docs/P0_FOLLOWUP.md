# P0 follow-up после 2.4.0-beta.1

Эти задачи сознательно **не входят** в prerelease `2.4.0-beta.1`: они требуют
отдельного ревью поведения и не должны блокировать проверку нового каркаса.
Ветка: `refactor/p0-followup` (создаётся от `main` после приёмки 2.4).

## 1. Выбор ребёнка

Сейчас `AppRoot` берёт первого ребёнка из `profile.children`. Нужно:

- хранить выбранного ребёнка в `SessionStore` (`studentId` + `personId`);
- показывать переключатель, если детей больше одного;
- при смене ребёнка пересоздавать `MeshClient.profileId`, сбрасывать кэши
  рейтинга/оценок и обновлять виджет;
- не ломать QR-вход: после логина выбирать `defaultChild`, если он есть.

## 2. ViewModel/Repository для legacy-экранов

Сейчас `RankingScreen`, `MarksScreen`, `HomeworksScreen`, `ScheduleScreen`,
`FoodScreen`, `MoskvenokScreen`, `ProfileScreen` и `SettingsScreen` сами
вызывают `MeshClient` и держат состояние в `remember`.

Нужно:

- вынести загрузку в репозитории;
- завести `ViewModel` и `UiState` на каждый экран;
- сохранить кэш при повороте экрана и очищать его при logout;
- добавить тесты на состояние: загрузка → успех, загрузка → ошибка,
  повтор после ошибки, устаревший ответ после смены недели/предмета.

## 3. Разрешение на уведомления

`TokenRefreshWorker` проверяет `POST_NOTIFICATIONS`, но приложение не
запрашивает разрешение. Нужно:

- запросить разрешение при первом успешном входе (не на старте);
- объяснить, зачем оно (продление сессии), и не показывать запрос повторно
  после отказа;
- не блокировать вход, если пользователь отказался.

## 4. Тесты нового слоя

Добавить:

- JVM-тесты `MeshAttendanceRepository` на фейковом `MeshClient`/HTTP;
- тест `WidgetSnapshot` (JSON → объект → JSON, null-поля);
- Compose UI-тест нижней навигации: четыре вкладки + «Ещё» → лист;
  в `SharedPreferences`.

## 5. Устойчивость посещаемости

- Проверить границу недели в разных часовых поясах (МЭШ отдаёт ISO-даты).
- Ограничить одновременные загрузки при быстром переключении недель
  (отменять предыдущий запрос).
- Показывать частичный результат, если один из двух endpoint'ов упал
  (сейчас падает весь экран).

## 6. Виджет

- Обновлять снимок не только при старте, но и по `WorkManager` раз в 30 минут.
- Не делать четыре сетевых запроса, если виджет не добавлен на домашний экран
  (`AppWidgetManager.getAppWidgetIds`).
- Добавить компактный layout для 2×1 и проверить тёмную тему на реальном
  лаунчере.

## 7. Чистка

- После перевода всех экранов на DTO убрать `JsonElement`-ветки из
  `MeshClient` и лишние `normalize*`-методы.
- Удалить неиспользуемые ресурсы и старые строки `Words`, если они больше не
  встречаются.
