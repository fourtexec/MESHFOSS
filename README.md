# Mesh Ranker

Android-приложение для **МЭШ** (Московская электронная школа): дневник, расписание, оценки, домашние задания, питание и баланс, рейтинг и профиль ученика.

- Платформа: Android (minSdk 24, targetSdk 35)
- Язык: Kotlin, UI — Jetpack Compose (Material 3)
- Сборка: Gradle + GitHub Actions

## Возможности

- **Вход** в МЭШ — QR-код, школьный логин или вход через `school.mos.ru` (токен перехватывается автоматически).
- **Расписание** уроков по дням с переключением дат.
- **Домашние задания** с отметкой «выполнено», просмотром по предметам и датам.
- **Оценки** и графики, итоговые оценки с выбором учебного года.
- **Предметы** и статистика.
- **Еда и баланс** — состояние питания, баланс лицевого счёта, меню комплексных обедов, предзаказы, переключатель платного/льготного питания. Недоступные дни питания пропускаются при перелистывании.
- **Рейтинг** учеников с дневным кэшем.
- **Профиль** и **настройки** — темы оформления, переключение языка (ru/en).
- Автоматическое обновление токена МЭШ в фоне (WorkManager).

## Сборка

Сборка выполняется автоматически в **GitHub Actions** при push в `main`: запускаются JVM-тесты ядра и собирается подписанный release-APK, который публикуется в GitHub Releases с автоматически растущей версией.

Локальная сборка не требуется. Готовый APK можно скачать со страницы [Releases](../../releases).

### Локальная сборка (по желанию)

Требуется JDK 17 и Android SDK (compileSdk 35).

```bash
./gradlew assembleDebug
```

Release-сборка с подписью — через переменные окружения `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` (как в CI) либо файл `keystore.properties` локально.
