# MESHFOSS

Свободный (GPLv3) Android-клиент для **МЭШ** (`school.mos.ru`): дневник,
расписание, оценки, домашние задания, посещаемость, питание, рейтинг,
«Москвёнок» и профиль ученика.

- Платформа: Android, minSdk 24, targetSdk 37
- Язык: Kotlin, UI — Jetpack Compose / Material 3 Expressive
- Сеть: Retrofit + Gson, OkHttp
- Лицензия: **GPLv3**

## Что нового в 2.5–2.6

- Пакеты по фичам: `core`, `data`, `ui`, `feature/*`, `app`, `widget`.
- Явный REST-контракт `MeshApiService` и DTO для Gson.
- **Посещаемость**: пропуски по урокам и фактические входы/выходы за неделю.
- **Три Glance-виджета**: статус урока с отсчётом, расписание и невыполненное ДЗ.
- **Мультиаккаунтность**: у каждого аккаунта свой токен, куки и кэш; переключение в «Ещё» → «Аккаунты».
- Экспериментальный вход по cookie JSON (например `mos_cookies.json`) — выбор файла или вставка JSON.
- **Автономный предпросмотр**: кнопка «Предпросмотр без входа» на экране входа открывает приложение с демо-данными без сети и токена.
- **Нативное решение ЦДЗ** — стабильная функция, включена по умолчанию: компактные inline-поля, M3E-анимации и жесты, ручное сохранение, подстановка верных ответов из прошлых попыток только в полностью совпавшие задания (и при старте новой попытки, и при продолжении уже начатой) и предупреждение перед завершением; документация — [`docs/cdz_api.md`](docs/cdz_api.md).
- **Анонимная аналитика 2.6**: id установки без ПИИ, все события install/update/error, отдельный heartbeat «client alive» раз в 24 часа и отфильтрованные ошибки через Retrofit + Gson; документация — [`docs/ANALYTICS.md`](docs/ANALYTICS.md).
- **2.6.1**: PLAIN снова режим по умолчанию (в том числе после сборок с Liquid по умолчанию); исправлены индексы SUB/SUP в inline-заданиях ЦДЗ, выравнивание подставленного текста и обрезание длинных вариантов; нижняя панель ЦДЗ больше не раздувается после возврата из «недавних» приложений.
- **2.6.2**: подстановка верных ответов из предыдущей попытки теперь работает и при продолжении уже начатой попытки, а не только при старте новой.
- Нижняя навигация: четыре частых вкладки + **«Ещё»** (посещаемость,
  «Москвёнок», питание, настройки); состав панели редактируется в «Ещё»
  (не больше четырёх вкладок, при меньшем числе — поровну).
- Обновлены зависимости и сборочный стек (AGP 9.5.1, Gradle 9.9.2,
  Kotlin 2.4.21, Compose BOM 2026.11.01).

### Liquid Glass (`Kyant0/AndroidLiquidGlass`)

- **Новый движок преломления**: интегрирована библиотека
  [`Kyant0/AndroidLiquidGlass`](https://github.com/Kyant0/AndroidLiquidGlass)
  (`io.github.kyant0:backdrop:2.0.1` и `io.github.kyant0:shapes:1.2.1`); стиль
  `Design.LIQUID` доступен в настройках, но по умолчанию используется `Design.PLAIN`.
- **Двухслойный `LayerBackdrop`**: базовый слой фона (`bgBackdrop`) питает
  карточки внутри списков, а комбинированный слой
  (`rememberCombinedBackdrop(bgBackdrop, contentBackdrop)`) передаёт живой
  прокручиваемый контент под плавающий таб-бар, капсулу действий в шапке и FAB.
- **Нативная линза и оптика iOS 26**: таб-бар и скользящая линза используют
  `Capsule()` и `drawBackdrop` с `vibrancy()`, `blur()`, AGSL-преломлением
  `lens` с хроматической дисперсией (Android 13+, с безопасным fallback на
  ранних версиях), направленным бликом `Highlight.Default` и внутренними тенями.
- **Инварианты сохранены**: иконки не увеличиваются при нажатии и
  перетаскивании — двигается только стекло; линза следует за пальцем,
  замедляется у центров вкладок и выбирает ближайшую левую вкладку при
  движении справа налево.

## Вход

Видимый способ входа — **QR-код** (а также кнопка автономного предпросмотра без
аккаунта). Дополнительно за красной экспериментальной кнопкой доступны
**явное окно WebView** `school.mos.ru` и ручной ввод токена. Это видимый
пользователю интерактивный вход, а не фоновый WebView и не способ делать
API-запросы. Поддерживается только МЭШ / `school.mos.ru`.

## Возможности

- Расписание, ДЗ с отметкой «выполнено», оценки и итоговые за учебный год.
- **ЦДЗ** (цифровые домашние задания): статус и баллы из LRS, описание и
  издатель материала, запуск одноразовой ссылкой в нативном решателе
  (по умолчанию) или в браузере, кнопка «Результат», предупреждение о таймере
  «Облака Знаний». Протокол — [`docs/cdz_api.md`](docs/cdz_api.md).
- Рейтинг класса, профиль ученика и родителя.
- Питание: меню, баланс, предзаказы.
- Посещаемость: пропуски и проходы.
- «Москвёнок»: карта и QR.
- Темы, язык (ru/en/hu/es/fr), проверка обновлений.
- Автообновление токена МЭШ в фоне.

## Сборка

Сборка и публикация идут через GitHub Actions (Android и Desktop запускаются
только при изменении своих файлов или при теге `v*`):

- **тег `v*`** — релиз; суффиксы `alpha`/`beta`/`rc` помечаются как prerelease;
- **push в main** — скользящие prerelease `nightly` и `desktop-nightly`;
- **ветки и PR** — только сборка, без публикации.
- Если коммит в `main` уже имеет релизный тег `v*`, nightly для него не
  собирается: остаётся только запуск стабильного релиза по тегу.

Текущая сборка: `2.6.2`.

Локально: `./gradlew assembleDebug` (нужны Android SDK 37 и JDK 17).

## Использовано из OctoDiary-kt

Идея виджета-статуса подсмотрена в `~/octodiary-kt` (`widget/StatusWidget.kt`):
показывать текущее/следующее событие и обратный отсчёт до него, а не просто
счётчики. Оттуда же взят приём с нативным `Chronometer` через `AndroidRemoteViews`,
чтобы отсчёт тикал без опроса сети. Код, API и модели данных MESHFOSS свои;
ничего из OctoDiary в проект не скопировано.
